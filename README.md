# ibadan-carbon-emissions-project
Geospatial study of atmospheric CO2 (XCO2) variation across Ibadan Metropolis, Nigeria (2018–2025), linked to land use, vegetation, land surface temperature, population, roads, and weather. Uses OCO-2, Sentinel-5P, Landsat, WorldPop, and GADM data to map emission hotspots and inform urban climate planning.
